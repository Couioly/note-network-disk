### 导出Python项目的requirements.txt文件

```bash
pip install pipreqs  # 需要提前安装模块
pipreqs ./ --encoding=utf8 --force
```

`pipreqs ./ --encoding=utf8 --force` 是 Python 项目中**精准生成依赖清单**的核心指令，相比 `pip freeze` 更贴合实际开发需求，我会拆解每个部分的作用，结合你的 QQ 音乐项目讲清楚它的价值：

#### 一、指令整体作用

这句指令的核心是：**分析当前项目目录（`./`）下所有 Python 文件的代码，自动识别并导出「项目实际用到的第三方依赖」到 `requirements.txt` 文件**，而非像 `pip freeze` 那样导出环境中所有安装的包（包括无用的）。

#### 二、逐参数拆解

|参数|具体作用|对你的 QQ 音乐项目的意义|
|---|---|---|
|`pipreqs`|指令主体，是一个第三方工具（需先 `pip install pipreqs` 安装），用于分析代码依赖|替代 `pip freeze`，避免把环境中无关包（比如你装的其他库）混入 `requirements.txt`|
|`./`|指定要分析的目录为「当前项目根目录」（`.` 代表当前目录）|扫描你的 `main.py`/`tool.py`/`config.py` 等所有 Python 文件，只抓项目真用的依赖|
|`--encoding=utf8`|指定读取 Python 文件时的编码为 UTF-8|解决中文注释 / 字符串导致的「编码错误」（你的项目中如果有中文注释 / 歌单名称，必加这个参数）|
|`--force`|强制覆盖已存在的 `requirements.txt` 文件|如果你的项目已有旧的 `requirements.txt`，直接替换成新的，不用手动删除旧文件|

#### 三、和 `pip freeze > requirements.txt` 的核心区别（关键）

| 特性    | `pipreqs ./ --encoding=utf8 --force` | `pip freeze > requirements.txt` |
| ----- | ------------------------------------ | ------------------------------- |
| 依赖范围  | 只导出项目**实际用到**的包                      | 导出环境中**所有安装**的包（冗余）             |
| 适配场景  | 项目交付 / 分享（精简依赖）                      | 环境备份（全量导出）                      |
| 对你的项目 | 只包含 `requests`/`execjs` 等必要包         | 会混入 `numpy`/`pandas` 等无关包       |

举个例子：

你的 QQ 音乐项目只用到 `requests`、`execjs`、`fake-useragent` 3 个包，但你的 Python 环境里还装了 `pandas`、`matplotlib` 等其他库：

- 用 `pipreqs`：`requirements.txt` 只有 3 行（精准）；
- 用 `pip freeze`：`requirements.txt` 有几十行（包含所有包，冗余）。

#### 四、使用注意事项（避坑）

1. **先安装 pipreqs**：执行指令前必须先装工具，否则报错 `pipreqs: 未找到命令`：

```bash
pip install pipreqs
```

1. **编码参数必加**：如果你的 Python 文件有中文（比如注释、搜索关键词「邓紫棋」），不加 `--encoding=utf8` 会报 `UnicodeDecodeError`；
2. **覆盖确认**：`--force` 会直接替换旧文件，如果你想保留旧文件，可先备份再执行；
3. **特殊依赖识别**：如果你的代码里用了 `execjs` 调用 Node.js，但 `execjs` 是通过 `import` 引入的，`pipreqs` 能正常识别；但如果是手动调用 `subprocess` 执行 Node.js，`pipreqs` 不会识别 `npm` 包（比如 `base64-js`），这部分需手动加进 `requirements.txt` 备注。

#### 总结

1. `pipreqs ./ --encoding=utf8 --force` 核心是**精准生成项目依赖清单**，只保留实际用到的包；
2. `--encoding=utf8` 解决中文编码问题，`--force` 覆盖旧文件，`./` 指定扫描当前目录；
3. 对你的 QQ 音乐项目来说，用这个指令生成的 `requirements.txt` 更精简，别人拿到后一键安装就能运行，不会装无关包。
