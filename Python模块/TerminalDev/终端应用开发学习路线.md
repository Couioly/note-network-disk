### 4.3 组件化设计

```python
# 可复用组件
class BaseComponent:
    def render(self) -> str:
        raise NotImplementedError

class ProgressComponent(BaseComponent):
    def __init__(self, progress: float):
        self.progress = progress
    
    def render(self) -> str:
        return f"[{'█' * int(self.progress * 20)}]"
```
